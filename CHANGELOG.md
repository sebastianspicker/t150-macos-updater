# Changelog

All builds so far are local, ad-hoc signed builds. None has been notarized or
published as a release. Build numbers are in parentheses.

## 0.6.0 (7), 2026-10-18

- App icon: a racing wheel with a firmware chip, generated by
  `script/make_icon.sh`.
- Build picker: every build has a short name, a one-line description and a badge.
  "PS5 stutter fix" is marked "Recommended for PS5". The four other experimental
  builds are kept for completeness in a collapsed "Other experimental builds"
  group.
- Steps in the sidebar show a checkmark once done.
- Review and headlines use the short build names; the full name is still shown.
- After the PS5 stutter fix is installed, the app shows the next steps.
- Help has a disclaimer section.

## 0.5.1 (6), 2026-10-18

- Recommends "V35 + sibling mimic + T300 features + recorder" for the Assetto
  Corsa Competizione stutter on PS5, after it fixed the stutter on a tester's
  T150. Build descriptions, Help and the experimental acknowledgement now say
  which builds have been tried on a console.
- Documentation: new [firmware builds](docs/FIRMWARE_BUILDS.md) page, reworked
  README, user guide and validation record.
- No change to the engine, the firmware builds or their hashes.

## 0.5.0 (5), 2026-10-18

- Two more experimental builds, "+ RAW keepalive", for the sibling mimic and
  sibling mimic + T300 features images. The app now offers seven V35 builds, and
  each can switch to any other.

## 0.4.0 (4), 2026-10-18

- Two experimental diagnostic builds: "V35 + sibling mimic + recorder" and
  "V35 + sibling mimic + T300 features + recorder". They make the T150 answer the
  console like a T300 and record what the console sends.

## 0.3.0 (3), 2026-10-18

- Experimental build "V35 + fixes + PS5 stutter patch" behind a second
  acknowledgement.
- Official, fixes and the patch build can switch between each other.

## 0.2.0 (2), 2026-10-17

- Firmware targets: the engine can build a modified image from the official one
  with a compiled, hash-pinned patch table.
- First modified build, "V35 + fixes".
- A wheel already on V35 can switch between the official and fixes builds.
- Each update attempt gets its own session folder, so a failed preparation can be
  retried.
- Sessions saved by 0.1.0 are refused and need new backups.

## 0.1.0, 2026-10-17

- First version: imports the official `2026_TTRS_2.exe` installer, backs up the
  wheel twice, updates a T150 to official V35 and verifies the complete flash.
